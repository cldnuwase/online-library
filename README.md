# Online Library Management System

A web-based library management system built with Laravel that allows users to browse, borrow, and return books, while administrators can manage books and user accounts.

## Features
- User authentication and authorization
- Book management (CRUD operations)
- Book borrowing and returning system
- User dashboard
- Admin dashboard
- Book search functionality
- Status tracking for borrowed books
